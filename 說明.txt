一、需求摘要
--------------------------------------------------------------------
在「線上授信審件」查詢結果表格中，於「票查日期」之後新增兩欄：
  1. 上傳財力證明：行為比照「上傳票查」
       - 已有財力證明檔 → 顯示「財力證明」超連結（開啟影像）
       - 案件狀態 ≠ 3（完成）→ 顯示「上傳」超連結
  2. 財力證明日期：比照「票查日期」，為最後一次上傳成功的日期（yyyyMMdd）

資料存放於 PC_Image（與 PC_RPA 同一資料庫，使用 connstr 連線）。


二、已確認的設計決策
--------------------------------------------------------------------
  1. PC_Image 欄位：SeqNo, IDNO, BranchId, Account, Kind, Type, ImgType,
     FileId, FileExtension, CreateUser, CreateDate
  2. 一筆授信申請（SeqNo）最多僅一筆財力證明 → 以 SeqNo 為鍵。
  3. Kind、Type 皆取「該筆授信資料本身」的值（PC_OLAccount.Kind 申請項目、
     PC_OLAccount.Type 申請種類）。
     實作方式：INSERT 時直接以 SeqNo 從 PC_OLAccount 帶出
     IDNO/BranchId/Account/Kind/Type，不需經由 URL 傳遞。
  4. ImgType = 財力證明類型，於上傳頁由使用者選取，固定寫在程式中：
       1.權狀　2.稅單　3.存款證明　4.集保他家庫存
  5. 寫入方式：有資料就 UPDATE，沒有就 INSERT（UPSERT）。
     重新上傳時 CreateDate 一併更新為當下，故「財力證明日期」= 最後上傳日。
  6. 財力證明「僅能上傳一個檔案」，前端與後端皆檢核。
  7. 影像系統文件類別代碼：C0039 = 財力證明（依據 IM/IM003.aspx.cs:80-81）。
  8. 同時上傳造成重複資料的問題，本次不處理（不加 unique index）。

【9】新增 App_Code/Service/OCA/PcImageDao.cs
     （寫法比照 App_Code/Service/OCA/PcRpaDao.cs）

using Cathay.Common.Utility;
using Cathay.DataService.DBConn;
using System;
using System.Data;
using System.Data.Common;

/// <summary>
/// PC_Image（線上授信-財力證明）資料存取
/// </summary>
namespace Cathay.Service
{
    public class PcImageDAO
    {
        public PcImageDAO() { }

        /// <summary>
        /// 有則更新、無則新增。
        /// 新增時 IDNO/BranchId/Account/Kind/Type 由 PC_OLAccount 依 SeqNo 帶出。
        /// </summary>
        public int UpsertPC_Image(PcImageVO vo)
        {
            int result;
            try
            {
                using (DbConnection dbConn = DataSetService.GetConnection("connstr") as DbConnection)
                {
                    string sql = @"
IF EXISTS (SELECT 1 FROM PC_Image WHERE SeqNo = @SeqNo)
    UPDATE PC_Image
       SET ImgType = @ImgType, FileId = @FileId, FileExtension = @FileExtension,
           CreateUser = @CreateUser, CreateDate = GETDATE()
     WHERE SeqNo = @SeqNo
ELSE
    INSERT INTO PC_Image (SeqNo, IDNO, BranchId, Account, Kind, Type, ImgType, FileId, FileExtension, CreateUser, CreateDate)
    SELECT SeqNo, IDNO, BranchId, Account, Kind, Type, @ImgType, @FileId, @FileExtension, @CreateUser, GETDATE()
      FROM PC_OLAccount
     WHERE SeqNo = @SeqNo
";
                    System.Collections.ArrayList fNames = new System.Collections.ArrayList();
                    System.Collections.ArrayList fValues = new System.Collections.ArrayList();
                    fNames.Add("SeqNo"); fValues.Add(vo.SeqNo);
                    fNames.Add("ImgType"); fValues.Add(vo.ImgType);
                    fNames.Add("FileId"); fValues.Add(vo.FileId);
                    fNames.Add("FileExtension"); fValues.Add(vo.FileExtension);
                    fNames.Add("CreateUser"); fValues.Add(vo.CreateUser);

                    DbParameter[] dbParams = DataSetService.getTableParams(fNames, fValues, dbConn);
                    result = DBHelper.ExecuteNonQuery(dbConn, CommandType.Text, sql, dbParams);
                }
            }
            catch (Exception ex)
            {
                throw ex;
            }
            return result;
        }
    }
}

  ※ 若 PC_OLAccount 查無該 SeqNo，INSERT ... SELECT 會新增 0 筆，回傳 0，

     票查是否比照限制需另行決定（會影響 IASMAT006 / IASMAT0061）。
  3. 列表目前不顯示財力證明類型（ImgType）；如需顯示，可於清單 SQL 加取
     I.ImgType 並在畫面轉成中文名稱。
